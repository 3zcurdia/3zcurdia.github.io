# Personal Site

Personal blog, contact and portfolio site.

Built with [Bridgetown](https://www.bridgetownrb.com/). Requires Ruby (see
`.ruby-version`) and Node 24+ with yarn.

```bash
# Install dependencies
bundle install
yarn install

# Build the frontend assets (Tailwind CSS + JavaScript)
yarn build

# Build the site into output/
BRIDGETOWN_ENV=production bundle exec bridgetown build

# Development server (frontend bundler + site watcher)
bundle exec bridgetown start
```

SEO metadata is generated by `bridgetown-seo-tag`, while `bridgetown-sitemap`
produces `sitemap.xml` and `robots.txt`. Structured data (JSON-LD) lives in
`src/_components/schema.html`.
